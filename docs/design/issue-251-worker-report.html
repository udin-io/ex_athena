The report is built, not caught

Worker subagent_fqB0WqCf spent 794,377 input tokens and 17 minutes, wrote its codebase map, and handed back 545 characters saying the map was “delivered in the previous turn”. Compaction had already destroyed it, so no hand-back-time fix can reach it. Approving this gate for issue 251 settles what the transcript stores, what the summariser costs, and what happens when it fails.

In plain words

A helper’s write-up is whatever it happened to say last, and its earlier words are thrown away as it works. We start saving everything it says to a file as it says it, and when it finishes a second short-lived helper reads that file and writes the write-up. The report stops depending on the helper remembering to end well.

Compaction is why hand-back is too late. Compactors.Summary replaces everything between the pinned prefix and the last 6 messages with one digest, and EpisodicArchive keeps the sliced text in state.meta — in memory, dying with the process.

2. What this builds

  • Agents.Transcript — one NDJSON line per turn, beside the journal, under the parent’s cwd. Stateless open/write/close, so a killed worker keeps every line up to its last.
  • One new loop event. Loop.Inference.call/3 is the single path every conversational turn takes, and holds the turn’s full text whether or not the provider streamed. It emits {:assistant_turn, …} once per turn; Transcript.compose/3 writes it, as Journal.compose/3 already wraps the same on_event.
  • Agents.Summariser — reads the finished transcript, chunks it, summarises each chunk into a bounded block, combines them in one pass. That is the report.
  • read_worker_report gains source: "transcript" — verbatim turns, no second model run.

A line holds prose only — assistant text, turn number, timestamp. The journal already digests tool calls and results; a second copy is most of the bytes for none of the value.

3. Decisions to approve

QuestionSettled as
ToolsNone, so it cannot spawn or read files. Fresh Loop.run/2, chunk in the prompt, no inherited todos.
BudgetIts own iterations and clock, worker’s provider, same request queue.
FailureError, timeout or blank falls back to the worker’s final message, and the report says so.
Wall clockOne pass per chunk plus a combine. To be measured on a real run and put in the PR, not asserted.
Chunk capMiddle chunks dropped with a marker naming source: "transcript". Never a silent loss.

4. Not in scope

  • Changing compaction. The transcript makes it survivable, not different.
  • The handback turn (issue 237). Its text lands in the transcript like any other.
  • Summarising the orchestrator’s own run.

One consequence. The worker suffix says “Your FINAL message is the ONLY thing the orchestrator sees”. That stops being true, so it changes with the code.
