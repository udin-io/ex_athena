The last turn belongs to the report

A worker gets 30 minutes of working time and is brutal-killed at the wall, so its Result dies with the process. In session 4ee9e00f1ebf two of twelve workers died that way, one with all four files written and not a word said about them. This page is the architecture gate for issue 237. Approving it settles where the handback stage lives, which termination it ends on, and how the parent reads it.

In plain words

A worker gets a fixed slice of time, and today it is cut off the instant that time runs out, wherever it happens to be. This change keeps the end of the slice aside: shortly before the wall the worker is told to stop working and report, its tools are taken away for that one exchange so it can only write, and what it writes goes to whoever asked for the work — in its own words, not a summary assembled by someone watching from outside.

Time is the only budget that kills mid-thought. Every other ceiling lets the loop reach a turn boundary. That asymmetry is the bug.

2. What this ticket does

  • BudgetPressure.handback?/2 NEW — true once credited working time passes loop.handback_at_percent (default 83). Credited time, so a queued worker is never pushed.
  • ReAct builds that turn with no tool schemas and no tool protocol in the system prompt, plus one instruction: what was produced, what is unverified, what remains.
  • It halts on :budget_handback NEW, which Terminations.budget_exhaustion?/1 reports true, so the parent does not score it.
  • SpawnAgent routes it through the SUCCESS branch.
  • Two settings fields: the threshold, and the worker's 30-minute budget itself (agents.timeout_ms), today a source-only constant.

The kill stays. await_worker is untouched: a handback turn that overruns still meets Task.shutdown.

3. Where I depart from the ticket

  • Success, not a digest. budget_exhaustion?/1 only feeds the error branch, so it cannot by itself deliver the worker's own words. spawn_agent.ex:525 routes on Terminations.success?/1 instead, and :budget_handback is a success subtype. Category stays :capacity: it reported, it did not finish.
  • No tool_choice: :none. Sending no schemas is the provider-agnostic form; a none choice with no tools array risks a 400 on OpenAI-compatible local backends.
  • Wall clock alone, not the maximum of the three fractions.

4. Not in scope

  • The orchestrator's own budget — it carries no :agent_deadline_at, so the gate cannot fire for it.
  • The 75% advisory nudge, unchanged.
  • Retrying a handed-back worker.
