Getting the file out of the browser

A run ends by naming a file it wants reviewed — a brief, a report, a mock. The web UI prints that path as text, renders HTML as source in a <pre>, and serves no bytes, so approving a mock means opening a shell on the host. This page is the gate for issue 269. Approving it settles where the root comes from, what the preview may do, and when a path becomes a link.

In plain words

When the assistant names a file that really exists in the folder you opened, the name becomes clickable: one click shows it, another saves it, and a web page shows as a page instead of as code. Anything that only looks like a file name, or sits outside that folder, stays ordinary text. The page is written by the model, so it is shown in a locked box that cannot reach your session.

2. What this ticket adds

  • Web.FileController.download/2 and preview/2, in the :browser pipeline so ExAthena.Web.Auth gates both. Download sends attachment for any file, binary included.
  • Web.FileLinks — the root travels as a Phoenix.Token, signed with the endpoint secret, minted only inside the authenticated LiveView. A client-supplied root would make the confinement check meaningless.
  • Web.Files.resolve/2 goes public and every request goes through it. It already calls ToolContext.within_roots?/2. No second path check is written.
  • Web.PathLinks.linkify/2, threaded into Markdown.render/2 at its text and inline-code leaves.

The previewed HTML is model-authored. The response carries Content-Security-Policy: sandbox allow-scripts; the iframe carries sandbox="allow-scripts" and no allow-same-origin. The document lands in an opaque origin: no cookies, no localStorage, no parent DOM, no forms, no top-level navigation. allow-scripts keeps a mock with tabs working, and is only dangerous paired with the token that is absent. Preview also sends nosniff, no-referrer and no-store, and serves .html and .htm only.

Three tests make a link: the conservative shape, File.regular?/1, and resolve/2 landing inside the root. Failing any one renders plain text. Fudu.Accounts.TenantClaim fails the shape on extension length, and existence too.

3. Not in scope

  • Directory download, archives, upload.
  • The viewer's 2 MB read cap.
  • Previewing Markdown, SVG or images — they download.
